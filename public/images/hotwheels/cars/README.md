# Sohan's garage car cutouts

This folder contains six custom generated, transparent die-cast-style cutouts for the garage scene:

- `bugatti-chiron.png` — Bugatti Chiron
- `mclaren-p1.png` — McLaren P1
- `ferrari-enzo.png` — Ferrari Enzo
- `lamborghini-huracan.png` — Lamborghini Huracán
- `dodge-charger.png` — Dodge Charger
- `porsche-911-gt3-rs.png` — Porsche 911 GT3 RS

They are Hot Wheels-inspired miniatures, not official product photography. Preserve the transparent backgrounds and full car silhouettes when placing them in display bays. Add more cars only when the image and exact model name are supplied.
