# Hot Wheels garage assets

- `garage-showroom.svg` is the current backdrop: a hand-drawn vector diorama of a graffiti garage — dark container box, nine ceiling spotlights, a black brick wall covered with a big outlined "SOHAN" wildstyle piece (red / bone white / sky blue, yellow tags, drips, splatter, green arrow, pink star), six white-lined parking bays on a polished concrete floor with colour reflections, and an amber-lit front lip. It is drawn entirely as vector paths (no photos, no external assets, no logos, no real-world trademarks) so it stays crisp at any size and identical on every device. The wall deliberately contains no cars — the six cutouts are layered over it by the page.
- `garage-showroom.png` is the previous generated empty showroom backdrop (warm amber display case with shelves, workbench and ramp). Kept only as an unused spare; nothing on the site references it anymore.
- Six custom generated transparent die-cast-style car cutouts are in `cars/`: Bugatti Chiron, McLaren P1, Ferrari Enzo, Lamborghini Huracán, Dodge Charger, and Porsche 911 GT3 RS. They are Hot Wheels-inspired miniatures, not official product photography or official Hot Wheels artwork. Each PNG is cropped to the car's true edges so its bounding box is exactly the silhouette, and all six are parked side by side at the same width in the page's bay layout.
